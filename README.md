# Домашнее задание: Модульное тестирование и работа с API

Проект включает в себя реализацию unit-тестов для базовых алгоритмов на Python и автоматизированное тестирование API Яндекс.Диска.

## Структура проекта
- `acquaintance.py` и `tests/test_acquaintance.py`: Задача на сопоставление пар из списков.
- `get_race_winner.py` и `tests/test_get_race_winner.py`: Задача на определение победителя гонки по дистанции.
- `winners_check.py` и `tests/test_winners_check.py`: Задача на фильтрацию списка чеков.
- `ya_disk.py`: Класс `YaDiskManager` для взаимодействия с Яндекс.Диск API.
- `tests/test_ya_disk.py`: Набор тестов для `YaDiskManager`, включая мокирование сетевых ошибок.
- `.env.example`: Шаблон файла конфигурации для хранения токенов.
- `requirements.txt`: Зависимости проекта.

## Описание класса YaDiskManager

Класс `YaDiskManager` предоставляет интерфейс для управления папками на Яндекс.Диске через REST API.

### Основные методы:
1. **`create_folder(folder_name: str)`**:
   - Отправляет `PUT`-запрос для создания папки.
   - Возвращает статус-код HTTP (например, 201 при успехе).

2. **`delete_folder(folder_name: str)`**:
   - Отправляет `DELETE`-запрос для удаления папки.
   - Возвращает статус-код HTTP.

3. **`find_folder(folder_name: str)`**:
   - Отправляет `GET`-запрос для проверки существования папки.
   - Возвращает 200, если папка найдена, 404 — если нет.

### Обработка ошибок:
Методы класса используют централизованную обработку сетевых исключений библиотеки `requests`:
- `Timeout` -> возвращает `504` (Gateway Timeout).
- `ConnectionError` -> возвращает `502` (Bad Gateway).
- `RequestException` -> возвращает `500` (Internal Server Error).

## Подготовка к запуску

### 1. Установка зависимостей
Для установки зависимостей выполните команду:
```bash
pip install -r requirements.txt
```

### 2. Настройка окружения
Для работы с Яндекс.Диск API необходимо создать файл .env на основе примера:
1. Создайте в корне проекта файл с именем .env.
2. Скопируйте содержимое из .env.example.
3. Замените `ВАШ ТОКЕН` на ваш реальный `OAuth-токен` от Яндекс.Диска (получить его можно на [`Яндекс.Полигон`](https://yandex.ru/dev/disk/poligon/)).

Примечание: Переменная `BAD_YD_TOKEN` уже заполнена некорректным токеном для тестирования негативных сценариев.

## Запуск тестов
Примечание: Для Windows замените команду `python3` на `python`
### Unit-тесты
Для проверки базовых функций выполните команду:
```bash
python3 -m pytest --tb=short -v tests/test_acquaintance.py tests/test_get_race_winner.py tests/test_winners_check.py
```

### Тестирование API Яндекс.Диска
Для запуска тестов API используйте:
```bash
python3 -m pytest --tb=short -v tests/test_ya_disk.py
```

### Запуск всех тестов сразу
Чтобы запустить полный набор тестов в проекте, просто выполните:
```bash
python3 -m pytest --tb=short -v
```

## Особенности реализации
Для обеспечения надежности и независимости тестов от реального состояния сети в проекте были применены следующие подходы:

* **Мокирование (Mocking):** В тестах API Яндекс.Диска используется библиотека `unittest.mock` (метод `patch`). Это позволило эмулировать сетевые исключения (`Timeout`, `ConnectionError`, `RequestException`) без необходимости реального обрыва соединения. Использование `patch` гарантирует, что тесты запускаются мгновенно и не зависят от стабильности интернет-соединения или доступности серверов Яндекса.

* **Фикстуры (Fixtures):**
  Используется `pytest.fixture` для управления состоянием папки (`clean_folder`), что позволяет приводить окружение к исходному состоянию до и после выполнения тестов.
